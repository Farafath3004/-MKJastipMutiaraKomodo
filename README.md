# 🚚 Jastip Mutiara Komodo Express

Website resmi **Jastip Mutiara Komodo Express**, layanan jasa titip dan pengiriman barang dari **Surabaya ke Indonesia Timur**.

## 🌐 Demo Website

🔗 https://farafath3004.github.io/-MKJastipMutiaraKomodo/

---

## 📌 Tentang Proyek

Website ini dibuat sebagai media informasi dan promosi digital untuk Jastip Mutiara Komodo Express.

Layanan yang disediakan meliputi:

- 📦 Pengiriman Paket
- 🛒 Jasa Titip Marketplace
- 🏍️ Pengiriman Motor
- 📺 Pengiriman Barang Elektronik
- ✈️ Bantuan Tiket & Travel
- 🤝 Layanan Agen

---

## 🚀 Cara Menjalankan

Clone repository

```bash
git clone https://github.com/Farafath3004/-MKJastipMutiaraKomodo.git
```

Masuk ke folder project

```bash
cd -MKJastipMutiaraKomodo
```

Kemudian buka file

```
index.html
```

menggunakan browser.

Atau gunakan **Live Server** pada Visual Studio Code.
